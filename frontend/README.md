# frontend

The site itself. Reads the static `resume.json` generated by `pipeline` at
build time — it never talks to Google at runtime (decision 2).

No frontend framework has been chosen yet — see the "Open / deferred"
section of [docs/architecture-decisions.md](../docs/architecture-decisions.md).
This package is currently just a workspace placeholder (depends on `schema`)
so the framework can be added here once that decision is made.
